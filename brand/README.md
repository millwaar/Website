# Millwaar brand assets

| File | Use |
|---|---|
| `millwaar-logo-on-dark.svg` / `png/…on-dark.png` | Full logo for dark backgrounds |
| `millwaar-logo-on-light.svg` / `png/…on-light.png` | Full logo for light backgrounds |
| `millwaar-logo-white.svg` / `-black.svg` | Single-colour versions (print, coloured backgrounds) |
| `millwaar-mark.svg` / `png/millwaar-mark-*.png` | Icon only (avatars, profile pictures) |
| `millwaar-mark-white.svg` / `-black.svg` | Single-colour icon |
| `png/millwaar-social-1200x630.png` | Link preview / social banner |
| `favicon/` | Browser and home-screen icons |

Colours: cyan `#22d3ee` → blue `#3b82f6` → violet `#8b5cf6` (gradient), dark `#07090f`, light text `#e8ecf4`.
Typeface: Space Grotesk (wordmark, converted to outlines, so no font install needed).
